# Tipografías

Deja aquí el `.ttf` u `.otf` de la tipografía del show. Se toma el primero por
orden alfabético, así que si hay varias, nómbralas `01-titulo.ttf`, `02-…`.

**Por qué está vacío:** las tipografías del sistema (Impact, Arial Narrow Bold)
sirven perfectamente para probar, pero no son redistribuibles: no pueden vivir
en el repo. Mientras no haya una aquí, `composition` usa la primera del sistema
que encuentre y lo registra en el log — suficiente para trabajar, no para
publicar, porque el resultado depende de la máquina.

Buenas candidatas libres para una miniatura (condensadas y pesadas):
Oswald Bold, Anton, Archivo Black, Bebas Neue, Barlow Condensed ExtraBold.
